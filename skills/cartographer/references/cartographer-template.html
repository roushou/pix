How to read this map

Each building is a code subsystem, sized by real lines of code and colored by zone. Solid edges are live control/data paths — hover a moving dot to see the payload that travels. Dashed edges are advisory or external links (client host, CI). Flat slabs are storage with no internal logic. The projection is isometric: near the top = entry surface, center = core domain, far right = the Roblox Studio plugin.
